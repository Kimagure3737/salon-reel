## 1. 本ガイドの位置づけと免責

**本ガイドは社内の納品前スクリーニング基準であり、法的判断・法的助言ではない。**

- 本ガイドの目的は「明らかにリスクの高い表現を納品前に検知し、修正または広告主への確認に回す」ことに限られる。個別案件の適法性の最終判断は、**広告主自身および広告主が依頼する弁護士・行政書士等の専門家**が行う。当社が報酬を得て個別の法律判断を提供することは弁護士法第72条（非弁行為の禁止）に抵触するおそれがあるため、行わない。
- **ただし薬機法は例外**：薬機法66条・68条は「何人も」を対象とする規制であり、違反クリエイティブを制作した当社・担当者個人が直接の摘発対象になりうる（第4章参照）。「最終判断は広告主」という整理は景表法には妥当するが、薬機法には通用しない。
- 本ガイドはv1.1であり、**弁護士による監修を経ていないドラフト**である。対外的に「弁護士監修のチェック体制」等と表現することを禁止する。
- 顧客向けに本チェックの実施を伝える場合の定型文（この範囲を超えない）：
  > 「納品前に社内基準（景品表示法・薬機法等の観点を含む表現ガイドライン）による一次スクリーニングを行っています。法的な適否の最終確認は広告主様にてお願いいたします。広告出稿・大規模配信の前には専門家（行政書士・弁護士）の確認を推奨します。」
- 判断に迷う表現は「問題なし」に倒さず、必ずリスク「中」以上として広告主・人間の責任者に上げる。

## 2. 景品表示法

### 2.1 基本：優良誤認・有利誤認

| 類型 | 定義（要旨） | 美容サロン広告での典型例 |
|---|---|---|
| 優良誤認（5条1号） | 商品・役務の品質・効果が実際より著しく優良と誤認させる表示 | 効果の断定（「必ず痩せる」）、根拠のない実績、盛ったビフォーアフター |
| 有利誤認（5条2号） | 価格・取引条件が実際より著しく有利と誤認させる表示 | 実売実績のない二重価格（取消線価格）、「今だけ」の常態化、実質条件を隠した「初回500円」 |

**2024年10月1日施行の改正で執行が強化されている点に注意：**

| 改正点 | 内容 |
|---|---|
| 直罰規定 | 優良誤認・有利誤認表示に対し、措置命令を経ずに100万円以下の罰金を科せる直罰が導入済み |
| 確約手続 | 是正計画の認定により命令を回避できる手続が導入済み |
| 課徴金加算 | 10年以内の再違反で課徴金1.5倍 |

つまり「指摘されてから直せばよい」は通用しない前提でチェックする。

**不実証広告規制（7条2項）**：効果を示す表示には、消費者庁から求められた場合に**15日以内に提出できる合理的根拠資料**が必要。根拠が広告主の手元にあるか不明な効果表示は、リスク「中」以上として広告主に根拠の有無を確認する。

### 2.2 美容サロン広告の典型NGパターン

| NGパターン | 抵触類型 | 理由 |
|---|---|---|
| 「必ず」「絶対」「誰でも」「100%」＋効果 | 優良誤認 | 効果保証。合理的根拠の立証はほぼ不可能 |
| 「−10kg」「ウエスト−15cm」等の断定的数値 | 優良誤認 | 全員に生じる結果と誤認させる。根拠資料が必須 |
| 「1回で実感」「即効」 | 優良誤認 | 即効性の断定 |
| 架空の体験談・架空のレビュー・水増し実績 | 優良誤認 | 事実に反する表示。AI生成の「お客様の声」も同罪（第6章） |
| 「通常30,000円→今だけ9,800円」（30,000円での販売実態なし） | 有利誤認 | 二重価格表示。比較対照価格には相当期間の販売実績が必要 |
| 「本日限定」「残り3枠」の常態化 | 有利誤認 | 実際には常時提供している条件を限定と偽る |
| 「モニター価格」なのにモニター条件（写真提供等）を明示しない | 有利誤認 | 取引条件の不明示 |

### 2.3 No.1表示・最上級表現（「日本一」「最高」「地域No.1」等）

消費者庁「No.1表示に関する実態調査報告書」（2024年9月26日公表）により、運用の考え方が明確化されている。**満たすべき条件は以下のすべて。**

| 条件 | 内容 |
|---|---|
| 客観的調査 | 恣意性・バイアスを排除した公正な調査に基づくこと。**ウェブサイト閲覧の印象だけで答えさせる「イメージ調査」に基づくNo.1は不当表示と判断される**（近年の措置命令の典型） |
| 比較対象の適切性 | 同種・類似の競合を適切に選定した比較であること |
| 出典の明記 | 調査機関・調査期間・調査対象（範囲・地域・n数）を広告上に明記 |
| 責任の所在 | 調査会社任せにできない。**法的責任は広告主**にある |

- 「顧客満足度No.1」「◯◯な人が選ぶNo.1」系は、上記を満たす例が実務上ほとんどないため、**当社の初期設定は「原則不使用」**。広告主から使用指示があった場合は根拠資料の実在を確認し、なければリスク「高」で差し戻す。
- 「最高」「日本一」「最安値」等の最上級表現も同様に客観的根拠＋出典明記がない限り不可。
- 安全な代替：客観的事実に置き換える（「◯◯検定1級ネイリスト在籍」「開業12年」「口コミ◯件・平均4.8（Googleマップ、2026年6月時点）」）。
- 口コミの扱い：件数・平均点など**集計値の引用は可**。口コミ**本文・スクリーンショットの転載**は著作権（投稿者）と媒体規約（Google・ホットペッパー等）の確認が必要＝原則、投稿者本人の同意と規約確認が取れるまで不可。
- 線引き：事実の優劣を主張しない**主観的・情緒的表現**（「極上のくつろぎ」「至福のひととき」等）は、具体的な品質・効果・実績の主張を伴わない限り優良誤認の直接対象になりにくい（推定）。ただし効果表現と結合した瞬間に対象となるため、迷ったら効果表現として扱う。

### 2.4 打消し表示のルール

消費者庁の実態調査報告書（2017年・2018年）に基づく留意点。**「※効果には個人差があります」と書けば何を言ってもよい、は成立しない。**

| ルール | 内容 |
|---|---|
| 視認性 | 強調表示と著しく異ならない文字サイズ・コントラスト・配置。動画では強調表示と**同一画面内**に、読み終えられる十分な秒数表示する |
| 動画特有 | 一瞬だけ表示・小さすぎるテロップ・音声の強調に対し文字だけの打消しは不可（推定：報告書の動画広告に関する考え方からの当社運用基準） |
| 矛盾の禁止 | 強調表示を実質否定する打消し（「必ず痩せる※痩せない場合があります」）はそもそも表示自体が不当 |
| 体験談 | 体験談＋「個人の感想です」だけでは、大体の人が同等の効果を得られるとの誤認を打ち消せない。**効果の分布（何%の人にどの程度）を示せない体験談型の効果訴求は原則不可** |

### 2.5 ビフォーアフター表現（景表法観点）

美容サロン（非医療）では、医療広告ガイドラインのようなB/A一律規制はないが、景表法の優良誤認リスクが直接かかる。**実写のB/Aを使う条件：**

1. **実在の顧客の、実際の施術前後の写真・動画であること**（撮影条件＝照明・角度・姿勢・メイク・加工の有無を前後で揃える。アフターのみ補正・加工は不可）
2. 本人の**書面同意**（広告利用範囲・期間を含む）があること
3. 施術内容・回数・期間を併記すること（「1回でこうなる」と誤認させない）
4. 平均から著しく外れた「特に成功した1例」を代表例のように見せないこと。実際の措置命令事例では、顧客でない人物の写真を顧客の施術前後のように表示したケースが処分されている（事件名・処分日の出典は弁護士監修時に確定：要確認）
5. 「個人差があります」は補助にすぎない（2.4のとおり、これだけでは免責されない）
6. **効果の保証（「あなたもこうなれる」）と結合させない**

**AI生成のビフォーアフターはこの条件を構造的に満たせないため、第6章のとおり原則禁止。**

### 2.6 景品規制（プレゼントキャンペーン）※簡易版

「フォロー＆いいねで◯◯プレゼント」等の企画は、表示規制とは別に**景品類の限度額規制**の対象になりうる（懸賞：最高額は取引価額の20倍または10万円の低い方、総額は売上予定総額の2%以内／総付景品：200円または取引価額の2/10の高い方）。本ガイドは表示規制を主対象とするため、**景品企画を含む案件は受注前に個別確認**とする。

## 3. ステマ規制（景表法5条3号告示・2023年10月1日施行）

「一般消費者が事業者の表示であることを判別することが困難である表示」は不当表示。規制対象・措置命令の名宛人は**広告主（サロン）**であり、投稿者や制作会社ではないが、当社は広告主を違反させないよう設計責任を負う。（※この名宛人の整理は景表法上のもの。薬機法は「何人も」規制であり、当社も直接責任を負う＝第4章）

| 場面 | PR表記の要否 | 当社の運用 |
|---|---|---|
| META広告枠での配信（広告として配信） | 広告であることが媒体上明瞭なため、追加のPR表記は原則不要 | ただし第6章のAI表示は別途必要になりうる |
| サロン公式アカウントのオーガニック投稿 | 自社アカウントと明瞭なら不要 | アカウント名・プロフィールでサロンの発信と分かることを確認 |
| インフルエンサー・顧客に**対価**（金銭、無償施術、割引、商品提供を含む）を渡して投稿させる場合 | **必要** | 冒頭または視認性の高い位置に「PR」「広告」「A社から施術の提供を受けて投稿しています」等。ハッシュタグの海に埋める・動画の最後に一瞬だけ、は不可 |
| 対価なし・自主的な口コミ | 不要 | ただし投稿内容への指示（「こう書いて」）を出すと事業者の表示になりうる。指示した場合は表記必要 |
| アフィリエイト経由の誘導 | **必要** | アフィリエイト広告も告示の対象 |

**媒体規約（法規制とは別に確認）**：Instagramで対価を伴う投稿を行う場合、PR文言に加えて**タイアップ投稿ラベル（ブランドコンテンツツール）**の使用が媒体規約上求められる。ステマ告示を守っていても媒体規約違反でリーチ制限・投稿削除等が起こりうるため、法規制と媒体規約の両方を確認する。

**絶対禁止**：第三者になりすました投稿、自作自演レビュー、AI生成人格による「一般ユーザー風」の推薦投稿（第6章）、Googleマップ等への報酬付きレビュー依頼。

## 4. 薬機法

### 4.1 適用の整理

薬機法の広告規制は「医薬品・医薬部外品・化粧品・医療機器」に適用される。エステ等の**施術（役務）そのもの**は直接の対象ではないが、次の2ルートでリスクが生じる。

1. 施術で使う**化粧品・美容機器の効能**を広告で標榜する場合 → 承認範囲を超える効能・未承認品の効能標榜は薬機法違反（66条・68条）
2. 施術の効果として**医療的な効果（治療・身体の変化）**を標榜する場合 → 薬機法・医師法（医行為の示唆）に加え、景表法の優良誤認に直結

**当社の直接責任（最重要）**：薬機法66条（誇大広告の禁止）・68条（未承認品の広告禁止）は「**何人も**」を主語とする規制であり、広告主だけでなく**制作した当社・担当者個人が直接の摘発対象**になりうる。広告代理店社員が薬機法違反容疑で逮捕された事例もある（2020年・ステラ漢方事件）。本章のチェックは顧客保護のためではなく**当社の自己防衛**であり、一切妥協しない。

### 4.2 非医療サロンが言える範囲／言えない範囲

| 表現 | 可否 | 理由・言い換えの方向 |
|---|---|---|
| 「痩せる」「脂肪が燃える・溶ける」「足痩せ」「部分痩せ」 | **NG** | 身体の変化＝医行為の領域。→「引き締まった印象へ」「ボディラインを整えるサポート」「サイズダウンを目指す」 |
| 「シミが消える」「シワがなくなる」「ニキビが治る」 | **NG** | 治療効果の標榜。→「うるおいを与え明るい印象に」「キメを整える」 |
| 「アンチエイジング」「若返る」「細胞が活性化」 | **NG** | 老化の防止・改善は医薬品的効能。→「年齢に応じたケア」「エイジングケア※年齢に応じたお手入れ」 |
| 「デトックス」「毒素排出」「老廃物を流す」 | **NG（老廃物系は特に）** | 身体機能への作用の断定。→「めぐりを意識したトリートメント」「リラックスケア」（それでも効果断定はしない） |
| 「永久脱毛」 | **NG** | 永久脱毛は医行為。サロンで言えるのは「除毛」「減毛」の範囲まで。→「ムダ毛ケア」「光による減毛ケア」 |
| 「マッサージ」 | **注意** | あん摩マッサージ指圧師（国家資格）の業務独占との関係で、無資格サロンの標榜はあはき法・医師法リスク。→「トリートメント」「ハンドケア」「もみほぐし」（要確認：自治体により指導実務に差） |
| 「医療級」「クリニック級」「ドクター推奨」 | **NG** | 医療との同等性の誤認＋推奨根拠の問題 |
| 「リラックス」「癒し」「うるおいを与える」「キメを整える」「引き締まった印象」「〜を目指す」「〜をサポート」 | OK | 事実の範囲・印象の範囲・化粧品効能の範囲 |

### 4.3 化粧品に言及する場合：効能表現56項目との関係

施術で使用する化粧品・美容液に言及するときは、厚労省通知「化粧品の効能の範囲の改正について」（平成23年薬食発0721第1号）が定める**56項目の範囲内**でしか効能を言えない。

- 56項目は「頭皮・毛髪を清浄にする」「肌にはりを与える」「肌にツヤを与える」「うるおいを与える」「日やけを防ぐ」等、**予防・清浄・保湿・整える・印象**の範囲。
- 第56項目「**乾燥による小じわを目立たなくする**」は、日本香粧品学会ガイドラインに基づく試験で効果確認済みの製品に限られ、**「乾燥による」の限定を省略できない**。「小じわが消える」「シワ改善」（医薬部外品の承認効能）をサロンの化粧品に流用するのはNG。
- メイクアップ効果（物理的に隠す・見せる）は「〜に見せる」と明示すれば可（「毛穴を目立たなく見せる」）。
- 業務用美容機器は、効能を標榜できる承認医療機器ではないため、**機器による身体変化の効能標榜は不可**。「温める」「ほぐす」等の物理的事実＋体感の範囲にとどめる。
- しばり表現（「乾燥による」等の要因限定）・メイクアップ効果の実務の型は、日本化粧品工業会「化粧品等の適正広告ガイドライン」を参照（第9章に出典）。

### 4.4 業種別NG表現（薬機法・関連法観点の早見表）

| 業種 | NG表現例 | 理由 |
|---|---|---|
| エステ | 「セルライト除去」「脂肪分解」「リンパの流れを改善」「ホルモンバランスを整える」 | 身体組織・機能への作用の断定＝医行為・医薬品的効能 |
| ネイル | 「傷んだ爪が治る」「爪が再生する」「深爪を治療」「巻き爪矯正で完治」 | 治療・再生の標榜。爪の疾患対応は医療の領域 |
| アイラッシュ | 「まつ毛が伸びる」「自まつ毛が増える」「育毛効果」「まつ育で太く長く」 | 発毛・育毛は医薬品（医薬部外品）の効能。化粧品のまつ毛美容液で言えるのは「ハリ・ツヤを与える」等まで |
| ヘア | 「髪が生える」「発毛」「白髪が黒髪に戻る」「抜け毛が治る」「頭皮の血行を改善」 | 発毛・治療効果は医薬品等の効能。「育毛」も薬用（医薬部外品）製品の承認効能であり、サロン施術には使えない |

## 5. 特定商取引法

### 5.1 特定継続的役務提供（エステが該当）

| 項目 | 内容 |
|---|---|
| 該当条件 | **エステティック**（痩身・美顔・脱毛等）で、提供期間が**1か月超**かつ金額が**5万円超**の契約 |
| ネイル・アイラッシュ・ヘア | 指定役務ではないため通常は対象外（推定：エステティックの定義＝皮膚の美化・体型を整える施術等に照らした一般的解釈）。ただし**痩身・脱毛メニューを併設する場合はその部分が対象になりうる** |

### 5.2 通信販売（オンライン決済の回数券・前売り・物販）

LPやリンク先でオンライン決済させる場合、特商法上の通信販売として**表示義務**がかかる。クリエイティブ本体ではなくLP側の問題だが、納品物にLPが含まれる場合は必須チェック。

- 必須表示：事業者名（氏名または登記名称）・住所・電話番号・代金と支払時期/方法・役務提供時期・返品/キャンセル特約
- 個人事業主のサロンでは氏名・住所の表示に抵抗があるケースが多い。省略の可否・請求時開示の運用は解釈に幅があるため、**該当案件は必ず人間の責任者経由で広告主・専門家に確認する**（当社では判断しない）。

## 6. 生成AI特有のリスク（本事業の核心）

当社の納品物はAI生成が前提であるため、本章の基準は**他章より優先して**適用する。

### 6.1 AI生成ビフォーアフターは原則使用禁止

**AI生成のB/A画像・動画は「実際の施術結果」ではない。それをB/A形式（左右比較・矢印・スライダー・「施術前/施術後」ラベル等）で見せることは、実在しない施術結果の捏造であり、優良誤認の最高リスク類型。**過去の措置命令には「顧客でない人物の写真を施術前後のように表示した」事例があり、AI生成はこれと同型である（出典は弁護士監修時に確定：要確認）。

| ルール | 内容 |
|---|---|
| 原則 | **B/A構図のAI生成画像・動画は禁止**（「イメージです」を付しても解除しない。B/A形式そのものが施術結果の表示と受け取られるため） |
| 実写B/AのAI加工 | 実在顧客のB/A写真へのAIレタッチ（肌補正・体型補正・明るさの前後差調整）も**禁止**。前後で条件が揃わなくなり2.5の条件を壊す |
| 実写B/A素材のAI動画化（image-to-video） | 当社の中核ワークフロー（SPEC §6「B/A写真→縦型動画広告」）に該当するため線引きを定義する：（a）施術前後の**静止画そのものは無加工**で表示（b）AI生成は**トランジション・背景・モーショングラフィックス等の演出に限定**し、人物には生成補間・再生成をかけない（c）生成過程で人物の肌・輪郭・体型が変化した素材は使用しない。**この線引きは弁護士監修の最重要論点（要確認）** |
| 例外（演出・世界観カット） | 施術結果を一切示唆しない**演出・世界観カット**としての使用のみ（例：ネイルデザインのイメージアート、サロン内観の雰囲気ムービー ※6.2の店舗実態の制約あり）。この場合も（1）B/A形式・「施術前後」等の文言を使わない（2）効果の数値・程度と紐づけない（3）6.3のAI表示を行う（4）広告主の事前承認を記録に残す、の4条件すべてを満たすこと |

### 6.2 実在しないAIモデル・人物の使用ルール

| 用途 | 可否 | 条件・理由 |
|---|---|---|
| 雰囲気・イメージモデル（「なりたい印象」の演出） | 条件付き可 | 施術結果・来店客・スタッフと誤認させない文脈で使用し、6.3のAI表示を行う |
| **「お客様の声」「体験談」への流用** | **禁止（例外なし）** | 架空の体験談＝優良誤認。AI人物に「通って3か月でこうなりました」と語らせる動画は捏造レビューであり、ステマ規制の趣旨にも反する |
| 「スタッフ紹介」「施術者」としての使用 | 禁止 | 実在しない施術者の提示は役務内容の優良誤認 |
| 店内・設備のAI生成画像 | 条件付き可 | 実店舗と誤認させる使い方（「当店の内観」等）は**禁止**＝実際より優良な店舗実態の誤認。使う場合は「イメージ」と明示し、実店舗と誤認させない構成＋6.3のAI表示を行う（6.1例外の4条件を準用） |
| 実在人物（芸能人・インフルエンサー・顧客）に似せた生成、「◯◯風」プロンプト | 禁止 | 肖像権・パブリシティ権侵害リスク。本ガイドの景表法外だが納品前チェック対象 |
| 実在しない資格・受賞・メディア掲載ロゴの生成 | 禁止 | 優良誤認＋商標権リスク |

生成物が既存の著作物・実在人物に酷似していないかの目視確認を、チェックリスト（第8章）に含める。

### 6.3 「AI生成である旨」の表示：現時点のルールと当社標準

| レイヤー | 2026年7月時点の状況 |
|---|---|
| 日本の法律 | AI生成コンテンツの表示（ラベリング）を一般に義務付ける法律は**ない**。AI推進法（2025年成立）は推進法であり表示義務を課していない。AI事業者ガイドライン（総務省・経産省）は透明性確保を推奨する任意の枠組み。ただし、AI生成であることを**隠した結果**として消費者が「実際の施術結果・実在の顧客」と誤認すれば、通常どおり景表法（優良誤認）で違法となる——義務がないのは「ラベル」であって「誤認させない義務」は既にある、と整理する |
| 海外・将来動向 | EU AI Act の透明性条項（2026年8月適用開始予定）、中国の識別弁法（2025年9月施行）、韓国AI基本法（2026年1月22日施行・生成AI出力の表示義務を含む）等、ラベリング義務化が国際的潮流。日本でも義務化議論が本格化する可能性が高い（推定） |
| META（配信媒体） | フォトリアルな人物等を含むAI生成・改変メディアについて開示を求めるポリシーが運用されており、2026年3月下旬の改訂でAI生成コンテンツの申告欄が必須化されたとの二次情報がある（**要確認：一次情報＝Meta広告規定・透明性センターの最新条項を、弁護士監修前かつ初回出稿前に必ず確認**）。AI開示を怠ると広告アカウント停止リスクがある前提で運用する |

**当社標準（法的義務の有無にかかわらず全納品物に適用）：**

1. フォトリアルなAI生成人物・シーンを含むクリエイティブには「画像（映像）はAIにより生成されたイメージです」を**クリエイティブ内に視認可能なサイズ・秒数で**表示する（打消し表示の視認性ルール＝2.4を準用）
2. META出稿のAI開示設定は、**運用受託案件では当社が実施主体**として設定し、設定画面のスクリーンショット等で記録を残す。制作のみの案件では、開示設定の必要性をテキスト（書面・チャット）で広告主に案内し、案内の記録を残す
3. 明らかなイラスト・アニメ調は1.の対象外としてよいが、迷ったら表示する
4. AI表示は6.1・6.2の禁止事項を解除しない（「AIです」と書けばB/A捏造が許されるわけではない）

### 6.4 素材の権利（BGM・音源・フォント・ストック素材）※AI生成物に限らず全納品物に適用

動画広告で最も事故が起きやすい権利領域。景表法より先にここで顧客に実害を出しうるため、納品前チェックの必須対象とする。

| 素材 | ルール |
|---|---|
| BGM・効果音 | **商用広告利用可のライセンスを個別確認**。楽曲は著作権（JASRAC/NexTone管理）に加え**原盤権は個別許諾**が必要。CapCut等の編集アプリ内音源・SNS提供音源は「個人利用のみ可・広告利用不可」の制限が一般的であり、広告への流用は原則不可 |
| フォント | 商用利用・動画/広告への使用・ロゴ化の可否はフォントごとにライセンスが異なる。使用フォントのライセンス範囲を確認 |
| ストック素材（写真・映像・イラスト） | ライセンス範囲（広告利用・改変・人物モデルリリースの有無）を確認。「エディトリアル限定」素材の広告転用は不可 |
| AI生成物の権利 | Higgsfield等の利用規約上、出力物の商用利用可否・権利帰属・無保証条項を確認（SPEC §12ゲートと接続） |

## 8. 納品前チェックリスト（制作物1本ごと）

**運用ルール：1つでも「いいえ／不明」があれば納品保留。「不明」は広告主確認へ。判断に迷ったらリスク「中」として人間の責任者に上げる。**
（A〜Gのうち、根拠資料・販売実績・特商法表記・承認フロー等の顧客単位項目は、将来「案件カルテ」方式への二層化を検討＝運用改善の別課題）

### A. 景品表示法
- [ ] 「必ず」「絶対」「100%」「誰でも」「即効」等の効果保証表現がない
- [ ] 効果・実績の数値（−◯kg、◯%等）には、広告主が15日以内に提出できる合理的根拠資料の存在を確認した
- [ ] No.1・最上級表現（日本一・最高・最安等）を使っていない／使う場合は調査出典・期間・範囲を明記し根拠資料を確認した
- [ ] 二重価格（取消線価格）の比較対照価格に販売実績があることを確認した
- [ ] 「今だけ」「限定」の期限・条件が事実であり、明記されている
- [ ] 打消し表示（※注記）は強調表示と同等の視認性で、動画では十分な秒数・同一画面に表示されている
- [ ] 体験談を効果の証明として使っていない（「個人の感想です」頼みの効果訴求がない）

### B. ステマ規制
- [ ] 対価（金銭・無償施術・商品提供）を伴う第三者投稿には「PR」等の明瞭な表記がある
- [ ] なりすまし投稿・自作自演レビュー・報酬付きレビュー依頼の要素がない

### C. 薬機法・関連法
- [ ] 「痩せる」「治る」「消える」「若返る」「生える」「伸びる（毛・爪）」等の身体変化の断定がない
- [ ] 化粧品への言及は効能56項目の範囲内（「乾燥による小じわ〜」は限定文言つき）
- [ ] 「永久脱毛」「マッサージ」「医療級」等の医療・資格関連ワードがない
- [ ] 業種別NG表現（4.4の表）に該当しない

### D. 特定商取引法
- [ ] エステの1か月超・5万円超コースの広告に誇大表現がなく、解約権を否定する記載がない
- [ ] オンライン決済に誘導するLPには特商法表記（事業者名・住所・連絡先・返品条件等）がある／個人事業主の氏名表記の扱いは広告主・専門家確認済み
- [ ] 「初回◯円」の継続条件・総額が隠されていない

### E. 生成AI（最重要）
- [ ] 【前提・案件開始時に1回】使用生成ツールの商用ライセンス・利用規約上の禁止事項を確認済み（SPEC §12ゲート参照）

- [ ] AI生成の店内・設備画像を実店舗と誤認させる使い方をしていない
