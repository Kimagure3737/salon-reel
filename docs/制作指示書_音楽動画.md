# 制作指示書：音楽動画（別タスク）

| 項目 | 内容 |
|---|---|
| 位置づけ | 美容サロンDFYとは別タスクの音楽動画制作。Higgsfield MCP＋Demucs＋Web手動リップシンクのパイプライン |
| 着手条件 | **トライアル3本目の完了（人間QC通過）後に開始** |
| 作成日 | 2026-07-04 |

## 制作フロー全体

```
1. 画像生成（MCP・Nano Banana Pro）
   → 2. 静止画→動画化（MCP・Seedance 2.0・15秒）
   → 3. 音源分離（Demucs・ローカル実行）
   → 4. リップシンク（Higgsfield Webサイトで手動）
```

## 1. 画像生成（Higgsfield MCP・Nano Banana Pro）

| カット | 内容 |
|--------|------|
| 女性 | マイクの前で歌う直前の20代日本人女性・バストアップ |
| 男性 | アコースティックギターを弾いている日本人男性 |

- 実行時は `models_explore` でNano Banana Proの正確なモデルIDと対応パラメータを確認してから `generate_image` を実行（Claude Code）
- 生成前に `get_cost: true` で消費crをプリフライトし、実効原価ログに記録
- **保存先: 素材フォルダ** `C:\Users\tanaka\Projects\higgsfield\素材\`（なければ作成。ファイル名例: `music_female_vocal.png` / `music_male_guitar.png`）
- リップシンク前提のため、女性は**口元がはっきり見える正面〜やや斜めの構図**で生成する

## 2. 静止画→動画化（Seedance 2.0・15秒）

| カット | 動きの指定 |
|--------|-----------|
| 女性 | 歌に合わせて体が自然に揺れる動き（口は大きく動かさない＝リップシンクは後工程で付けるため） |
| 男性 | ギターの弦を弾く指の動き |

- `generate_video` で `model: seedance_2_0`、手順1の画像を `start_image` として使用（media_import または job_id 参照）
- 設定: **duration 15秒**・std・720p・`generate_audio: false`（音声は元音源を使うため必ずoff）・9:16（仮定。16:9希望なら実行時に指定）
- **QC最重点（男性カット）**: ギターを弾く指の本数・関節の破綻。破綻時は「指のアップを避けた引きの構図」に変更して再生成
- 消費crはMCP取引履歴から実効原価ログに自動記録

## 3. 音源の用意（変更：AI音楽生成・2026-07-04改訂）

- 既存音源がないため、**Suno AI（suno.com）またはUdio（udio.com）でオリジナル楽曲を生成**する方針に変更
- 条件: 女性ボーカル・アコースティックギター伴奏のポップス・日本語歌詞（またはハミング）・15〜30秒
- 生成後、wavまたはmp3でダウンロードし素材フォルダに保存（例: `素材\music_song.mp3`）
- **Demucsによるボーカル分離は省略**（AI生成曲をそのままリップシンクに使用）。ただしリップシンクの口の同期が悪い場合のフォールバックとして、`demucs --two-stems=vocals` でボーカルだけ抽出して再試行できる（環境はインストール済み・温存）
- 権利の注意: Suno/Udioとも**商用利用の可否はプラン依存**（無料プランは非商用が一般的（推定・要確認））。公開・商用利用する場合は加入プランの利用規約を確認すること

## 4. リップシンク（Higgsfield Webサイトで手動）

- **MCPからは実行不可**のため、Higgsfield Web（hirstjuice1669）上で手動実施
- 手順2の女性動画＋手順3の `vocal_only.wav` をアップロードし、リップシンク機能を適用
- 実施後、消費crをMCP取引履歴で確認し実効原価ログに記録（手動実施分も記録漏れさせない）

## 5. 権利・表示の注意（実行前に必ず確認）

- **音源の権利**: Demucsで分離しても元楽曲の権利（著作権・原盤権・実演）は消えない。使用する音源が「自作曲・権利処理済み・ライセンス上リップシンク動画への利用可」であることを実行前に確認（表現ガイド6.4の考え方を準用）
- **公開する場合**: フォトリアルなAI人物を含むため「AIにより生成されたイメージです」等の表示を推奨（表現ガイド6.3の当社標準を準用）。実在アーティストに似せる指定は禁止（6.2）
- 本動画はサロンDFYの納品物ではないため第8章チェックリストの対象外だが、上記2点のみ必須とする
