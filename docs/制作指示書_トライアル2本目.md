# 制作指示書：トライアル2本目

| 項目 | 内容 |
|---|---|
| 位置づけ | トライアル制作計画 #2（標準方式＝複数クリップ構成で原価の中央値を実測） |
| 用途 | 営業デモ用サンプル。**実広告としての配信は不可**（架空サロン設定。1本目と同じ扱い） |
| 作成日 | 2026-07-04 |

## 1. 想定業種・サロンの種類（仮定）

- 業種: **ネイルサロン（プライベートサロン）**
- 設定: 都市部の個人経営ネイルサロン。完全予約制・丁寧なカウンセリングが売り（仮定・架空）
- ターゲット: 20〜30代女性、Instagramでネイルデザインを探す層

## 2. 動画の目的

- 新規集客・**デザインの世界観訴求**（「このサロンに行けばこういう指先になれる雰囲気」を見せる型）
- 営業デモとしては「複数カット構成＋字幕入りの標準的なリール広告」の品質見本

## 3. 尺・形式

| 項目 | 指定 |
|---|---|
| 尺 | 18〜25秒 |
| 画角 | 縦型 9:16 |
| 想定面 | Instagramリール／META広告 |
| 構成 | **3クリップ構成**＋字幕：①デザインカット（夏ネイルのマクロ）→②空間カット（サロンの雰囲気）→③仕上げカット（デザイン別アングル）＋テキストカードでCTA |
| 使用モデル | Kling 3.0（1本目と同条件で継続＝比較可能性のため）。**生成時のモード・尺・解像度の設定を今回は記録**（72cr/生成の内訳確認のため） |

## 4. クレジット予算（1本目の実測ベース）

| 項目 | 数値 |
|------|------|
| 実測単価 | 72cr/生成（1本目実測） |
| 想定消費 | 3クリップ×再生成1.5倍＝4〜5生成 ≒ **288〜360cr（推定）** |
| **中断ライン** | **消費400cr到達で一旦停止し方針見直し**（現残高1,138crの35%） |

※ネイルのマクロは「指」が映るためAI生成の失敗が出やすく、再生成率は1本目（ゼロ）より上がる前提（推定）。

## 5. 訴求ポイント

優先順に：
1. **デザインの世界観・季節感**（7月＝夏ネイル：クリアベース・シェル・ミントなど）
2. 完全予約制・マンツーマンの丁寧なカウンセリング（事実ベースの特徴）
3. 初回メニューの存在（価格は入れない。「初めての方向けメニューあり」まで）

テキスト案（編集で載せる）：
- フック（0〜2秒）:「夏の指先、そろそろ決めた？」
- 中盤:「マンツーマンのプライベートサロンで、じっくりデザイン相談」
- CTA:「デザイン一覧はプロフィールから」

## 6. 使用素材

- **実写素材: なし（フルAI生成）**
- 必須事項（表現ガイドv1.1）：
  - 「映像はAIにより生成されたイメージです」表示（6.3）
  - **AI生成デザインを「実際の施術例」と誤認させない**：「デザインイメージ」「サンプルデザイン」と明記（6.1例外の演出・世界観カット扱い。実例ポートフォリオのように見せるのは不可）
  - 実在店舗と誤認させない（6.2）
  - AI人物を「お客様」「スタッフ」として提示しない（6.2）

## 7. 指・手のリスク対策（本作の最大QCポイント）

| 優先 | 見せ方 | リスク |
|------|--------|--------|
| 推奨 | **ネイルチップ（付け爪）をスタンド・トレイに並べた静物マクロ**＝指を映さない | 破綻リスク最小 |
| 次点 | 指2〜3本までの部分アップ（爪にフォーカス、手全体を映さない） | 指の本数・関節の破綻に注意 |
| 避ける | 手全体・両手・指を開いたポーズ | 指崩れ頻発（推定）で再生成コスト増 |

## 8. NGワード・NG構図（表現ガイドv1.1準拠・ネイル特化）

**ワード：**
- 治療・再生系: 傷んだ爪が治る／爪が再生・生まれ変わる／深爪を治療／巻き爪矯正・完治／爪が伸びる（成長への作用）
- 保証・断定系: 絶対浮かない／絶対取れない／最強／100%キープ／必ず
- 最上級・No.1系: 地域No.1／最高の技術／日本一
- 有利誤認系: 今だけ・限定（事実でない場合）、取消線の二重価格
- 効果保証系: 誰でも◯週間もつ（根拠なき数値）

**構図：**
- ビフォーアフター構図の全面禁止（6.1）＝「施術前の爪→施術後」の比較は実写でもAIでも作らない

**素材権利（6.4）：**
- BGM・フォントは商用広告利用可ライセンスのみ

**プロンプト共通ルール（トライアル実測からの学習・全クリップに適用）：**
- 「steam / vapor / mist（湯気・蒸気・霧）」は**ネガティブプロンプトに必ず追加**（1本目QC知見：湯気の動きが不自然になりやすい）。プロンプト本文にも湯気・蒸気の描写を入れない

## 9. 参考にするトーン・雰囲気

- 明るくクリーンな上質感（白・ベージュ基調に夏色のネイルが映える配色）
- ビジュアル: 明るい自然光、白い机・大理石調トレイ・ガラス小物、浅い被写界深度のマクロ
- テキスト: 口語・カジュアル寄りのですます調（1本目よりややポップに）
- 音: 軽やかなポップ/チル系BGM（商用可ライセンス）
