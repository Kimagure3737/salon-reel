# Instagramアイコン戦略リサーチ（SALON REEL）

作成: 2026-07-05 ／ ディープリサーチ（101エージェント・敵対的検証済み）に基づく

対象: 日本市場・美容サロンオーナー向けBtoB「AI動画制作DFY」ブランド「SALON REEL」。
世界観=ラグジュアリー×清潔感、配色=ブラック×ゴールド／ホワイト×ゴールド、1:1・Instagram円形クロップ前提。

## 調査結果サマリー（信頼度付き）

### ① トレンド／② アイコン心理学【高信頼・複数ソース全会一致】
- **新規BtoBブランドは「抽象シンボル単体」を避け、ブランド名または頭文字（モノグラム）を含めるべき**。シンボルは名前と反復ペアリングされて初めて意味を持つ（＝認知ゼロの新興ブランドには不利）。
- ただし**円形・小サイズ（モバイル110×110px）ではフル横型ワードマークは可読性を失う**。→ **2文字モノグラム「SR」が「フルロゴタイプ」と「小サイズ可読性」を両立する最適解**。
- 小サイズ前提で**細部・ヘアライン・タグラインは排除、太めのストローク・低要素数・クリスプなエッジ**が必須。
- **円形クロップ対応：重要要素は中央配置、各辺約15%（横幅で約30%）の余白**を確保。

### ③ 日本市場【一部高信頼・一部証拠薄】
- 日本語ソースでも**企業アカウントは「ロゴ＋ブランドカラー」が基本**、人物写真は個人ブランド/クリエイター向け（＝BtoB企業のSALON REELは顔写真不適）。
- 高級サロン系は**モノトーン／チャコール＋ゴールドの高コントラスト**が定番。
- ⚠️ 「英字モノグラム(SR) vs 和文/ひらがな/記号」で日本市場の認知・CTRにどちらが有利かの**定量根拠は得られず**（オープンクエスチョン）。ブランド名がアルファベット表記（SALON REEL）で一貫している以上、英字モノグラムが自然と判断。

### ④ 競合調査【証拠薄・要追加調査】
- AI動画制作／サロン向けSNS運用・動画制作代行系の**実アカウントのアイコン実態データは今回のリサーチでは十分に取れなかった**。差別化の空白の特定は直接調査が必要（下記オープンクエスチョン）。

### ⑤ 配色の原則【原則は高信頼／具体HEXは中信頼】
- **ブラックは世界的に最も高級感と結びつく色**（権威・抑制された力）。推奨アンカー #0A0A0A 系。
- **ゴールドは大面積でなく小面積のプレステージ・アクセント**として使う。推奨 #C69B3C／#D4AF37 系。
- ⚠️ 正確なHEXはSEOブログ由来で恣意的。「黒=高級」「金=小面積アクセント」の原則は堅いが、#000/#111/#1A1A1A・#D4AF37/#A48111 等の代替も同等に妥当。数値は絶対視しない。

### 反証されて棄却された主張（採用しない）
- 「金＋黒/紺は高収入客を惹きつける」→ 効果の断定は不可（棄却）
- 「プロフィール写真では文字を避けるべき」→ **棄却＝モノグラムの文字は否定されない**（追い風）
- 「ワードマークが専門サービス企業のデフォルト」→ 棄却
- 「暖色アイボリー#F4EADEが純白より高級」→ 棄却＝**ホワイト×ゴールド案で純白を避ける根拠はない**

## 最終推奨案（1案に確定）

### 「SR」モノグラム・エンブレム ／ ブラック×ゴールド

BtoB新規ブランド×日本市場×AI動画業態の3条件すべてに整合する唯一の解。

| 項目 | 仕様 |
|---|---|
| コンセプト | ブランド頭文字「SR」を高コントラスト・セリフで組んだモノグラム。名前を内包するため認知ゼロでも意味が伝わり、2文字なので円形・110pxでも判読可能 |
| 形状 | 中央にSRモノグラム＋外周に細いゴールドの円環（Instagramの円形クロップと同調させ「割れない」設計） |
| 背景 | ディープブラック（マット）: **#0F0F0F**（代替 #0A0A0A / #111111）。※Instagram UIの白背景に対しダーク背景は沈まず最も目立つ＝小サイズで有利 |
| 文字色 | ゴールド。メタリック表現なら #B8862F→#E5C572→#C69B3C のグラデ、フラットなら **#D4AF37**（単色） |
| 文字 | モノグラム「SR」のみ（＝最小限）。「SALON REEL」ワードマークやタグラインはアイコン内に入れない（名前欄=表示名で担保） |
| 書体方向性 | クラシックな高コントラスト・セリフ（Didot/Bodoni系）＝ラグジュアリー。ただしサンセリフの権威表現も可。ストロークは110pxで消えない太さを確保 |
| レイアウト | モノグラムを中央約60〜70%の安全ゾーンに配置。上下左右に各約15%の余白 |
| 円クロップ対応 | 正方形四隅は切れる前提。要素は中央円内で完結。円環がクロップ縁のわずか内側に来るよう配置 |
| 納品サイズ | 1080×1080px（1:1）。32px相当に縮小しても「SR」が判読できることを確認 |

### なぜこの1案か（根拠の紐付け）
- **①②**: 新規BtoBは名前/頭文字を含めるべき × 小サイズはモノグラムが最適 → 「SR」がその交差点。抽象シンボル単体（前回Pattern2/3）は認知形成が遅れるため次点に降格。
- **③**: 企業=ロゴ+ブランドカラーが日本でも基本／人物写真は不適 → 顔なしモノグラムが正解。英字表記はブランド名と一貫。
- **⑤**: ブラック=最高級・ゴールド=小面積アクセントの原則に直合致。Instagram白UIで沈まないダーク背景が小サイズ視認で有利。
- **AI動画業態**: 動画性は「再生ボタン/リール」を足したくなるが、新規ブランドで要素を増やすと認知が遅れる（オープンクエスチョン参照）ため、**アイコンは清潔にSRのみ**。動画性は投稿・プロフィール文で表現する。

### 補足：ホワイト×ゴールドの位置づけ
純白×ゴールド（背景 #FFFFFF・文字 #C69B3C）は「清潔感」で優れ、名刺・LP・資料など**白地の媒体で使う派生版**として有効。ただしInstagramアイコン本体はダーク背景の方が小サイズで目立つため、**アイコンはブラック×ゴールドを主、ホワイト×ゴールドを副**とする2バリエーション運用を推奨。
