# SNS戦略ディープリサーチ（最終レポート）

| 項目 | 内容 |
|---|---|
| 実施日 | 2026-07-05 |
| 手法 | ディープリサーチワークフロー2回実行（検索5アングル並列→23ソース取得→主張ごとの敵対的検証3票制）＋収集データからの直接統合 |
| 限界 | 2回ともVerify工程途中でセッション上限に到達。【出典あり】タグの主張は一次ソース取得済みだが3票検証未完。運用開始前にTikTok/Instagramの現行ポリシー原文の一次確認を推奨 |
| 結論 | **方向性①（完全非開示）は実行不可。②主軸のハイブリッド（②70%・①改30%）を推奨** |

**根拠の凡例**：【検証済】＝敵対的検証3票通過の一次データ／【出典あり】＝一次ソース取得済み・検証未完／（推定）＝収集データからの推論

## 検討対象

- **方向性①**：AIと明かさずクオリティ動画としてそのまま投稿（ジャンルコンテンツとしてバズ→インバウンド）
- **方向性②**：「AIで作った」制作過程・ノウハウを見せる（AI関心層・サロンオーナー・BtoB見込み客への差別化）
- **①改**：①の修正版＝規定のAI表示は入れた上でジャンルコンテンツとして品質勝負

## 1. 批判モード

### 方向性①の弱点
- **自社ルールと正面衝突**：表現ガイドv1.1の当社標準「フォトリアルAI生成物にはAI表示」に違反。開始前から社内基準アウト
- **プラットフォームが「明かさない」を許さない**【出典あり】：TikTokはリアルなAI生成コンテンツのラベル義務化＋C2PAメタデータの自動検出ラベル（2024年5月〜）。Metaも検出シグナルで「AI info」ラベルを自動付与（完全生成物は可視ラベル）。YouTubeは開示義務＋反復未開示への執行措置（ストライク・収益化停止）を明言。隠しても勝手にラベルが付き「隠そうとした」事実だけが残る
- **「後から発覚」が日本型炎上の典型**【出典あり】：サクラクレパスはAI使用「疑惑」だけでポスター撤回・謝罪。ウテナ「潤い戦士モイスチャー」はリーガルチェック通過済みでも既存作品類似の感情反発で取り下げ。品質向上では炎上リスクは消えない
- **バズしても効果毀損**【検証済】：ビデオリサーチ「ひと研究所」2025年12月調査（2,593名）で、広告を「AI製」と認識した視聴者は購入・利用喚起スコアが低下。実写ですら最大71.4%がAIと誤認する市場で「隠すコストを払ってもどうせ疑われる」
- **ビジネスモデル不整合**（推定）：①のバズはB2C層に届くが、DFYの買い手はサロンオーナー。転換経路が間接的で、3人体制・資金50万円の時間軸に合わない

### 方向性②の弱点
- **AI抵抗層が受容層を上回る**【検証済】：JIAA 2025調査（3,840名）で生成AI広告に「抵抗感がある」約37% >「ない」約22%
- **「制作費0円」「30分で完成」フックは景表法リスク**（推定・表現ガイド2.2準拠）：実際はクレジット費・人時が掛かるため有利誤認の典型。根拠ある相対表現への置き換え必須
- **ノウハウ公開＝参入障壁の自己解体に見える**：ただしSPEC §14で「ワークフローは堀にならない」と定義済みのため実害は小さい。真のリスクは「ノウハウだけ消費されるフォロワー構成」（推定）
- **対人体験サービスとの相性**【出典あり】：「人間がやるべき仕事」に購買を挙げる層38.8%。「全部AIで済む」と聞こえるメッセージはサロンオーナーの職業的自己認識と衝突しうる

## 2. 賛成モード

### 方向性①（①改）が機能する根拠
- **視聴者はAIと見分けられない**【検証済】：AI広告の正答率6割弱〜7割。品質勝負の余地は実在
- **AI表示を入れても死なない**【検証済】：「AI明記で抵抗感が薄れる/安心」33.8% >「明記されても受け入れない」29.1%。表示＝敗北ではない
- **原価構造が投稿量勝負に向く**：実測30cr/本≒数百円。Reelsのリーチ獲得の前提（量×継続）に対する明確な優位（推定）
- **ステマ規制に抵触しない**【出典あり】：消費者庁のステマ規制は「広告か否かの開示」の規律で、AI開示は対象外

### 方向性②が機能する根拠
- **受容の境界線は「文脈の納得感」**【出典あり】：リポビタンD AI CM（2026年元日）は受容側。炎上は「隠した/雑」のケースに集中しており、最初から開示＋人間工程を見せる②は炎上構造の逆張り
- **ターゲットとメッセージが直結**（推定）：買い手＝サロンオーナーの関心は「集客動画を安く早く」。②の提示はそのまま商談の価値提案。テンプレ商品化・SaaS構想への動線も一直線
- **2026年開始の先行者優位**（推定）：AI開示義務化は国際潮流（韓国は義務化方針【出典あり】・EU AI Act透明性条項2026年8月適用）。規制が強まるほど「最初から開示」の信頼ストックが効く
- **検証済みデータが設計を直接支持**【検証済】：「明記で安心33.8%」は②（過程を見せる＝究極の明記）の受容基盤

## 3. リスク管理モード

| 項目 | ①改に集中 | ②に集中 | ハイブリッド（推奨） |
|------|-----------|---------|-------------------|
| 最悪シナリオ | バズしても問い合わせゼロ（B2C層のみ）で90日浪費 | AI抵抗層の反発蓄積／ノウハウだけ消費 | 発信軸がブレて中途半端（最大リスク） |
| 回避策 | プロフィール・CTAを「サロン向け制作サービス」に固定 | 人間のQC・コンプラ工程を必ず見せる／数字フックは根拠ある表現のみ | 1アカウント・1ターゲット（サロンオーナー）固定。②の投稿内で完成動画（①の品質）を見せる |
| 炎上対応 | AI表示が保険（「隠していない」事実） | 同左＋返信テンプレ事前用意 | 同左 |
| 工数配分 | SNSは2〜3人時/日が上限（DFY実案件が主業務）（推定） | 同左 | 制作1〜1.5人時＋企画・返信1人時/日 |

**撤退ライン**：
- 30日：平均再生500未満＋保存率1%未満 → フォーマット全面改訂
- 90日：問い合わせ3件未満 → SNS主軸を見直し・DM併用へ回帰
- 180日：成約1件未満 → SNSを補助チャネルへ格下げ

**段階計画**：30日＝型の探索 → 90日＝勝ちフォーマット集中・問い合わせ3件・モニター案件化 → 180日＝事例動画×②形式の「実績見せ」・テンプレ商品の先行予約テスト（推定）

## 4. 最終推奨：②主軸のハイブリッド（②70%・①改30%）

**理由**：
1. ①原型（完全非開示）は自社ガイド違反＋プラットフォーム開示義務＋発覚型炎上の三重リスクで棄却。**表現ガイドv1.1と整合するのは「AI表示を入れる」戦略のみ**
2. 検証済みデータは「AI認識→購買喚起低下」（①改の弱点）と「明記→安心33.8%」（②の支持）を示すが、当社の買い手はサロンオーナー（B2B）であり「AIで安く早く高品質」がそのまま購買理由になる
3. ②のフォーマット（素材→過程→完成動画）は完成動画の品質提示＝①の価値を内包する。逆は成立しない

**30日アクションプラン**：

| 週 | アクション | 数値目標（仮定） |
|----|-----------|----------------|
| 1 | アカウント設計／投稿テンプレ3型（A変身型・B制作過程型・C完成動画型）設計／表現ガイド準拠の定型文セット | 準備完了 |
| 2 | A/B/C各2本＝6本投稿（トライアル3本＋音楽動画を転用可）。全投稿AI表示＋コンプラチェック | 投稿6本 |
| 3 | 数値レビュー1回目：保存率・プロフィールアクセスで型の優劣判定→勝ち型に寄せて6本 | 累計12本 |
| 4 | 勝ち型軸に6本＋CTA強化（「1本お試し制作」導線）／30日レビュー・撤退ライン判定 | 累計18本・問い合わせ1件以上 |

**運用必須ルール**：全投稿にAI表示（ガイド6.3）／「制作費0円」等の絶対表現禁止・根拠ある相対表現のみ／施術結果と誤認させるB/A構図禁止（ガイド6.1）
