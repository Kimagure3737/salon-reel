# 制作指示書：トライアル1本目

| 項目 | 内容 |
|---|---|
| 位置づけ | トライアル制作計画 #1（最軽量方式で原価の下限を実測） |
| 用途 | 営業デモ用サンプル。**実広告としての配信は不可**（架空サロン設定のため。配信するのはPhase2以降・実顧客案件のみ） |
| 作成日 | 2026-07-04 |

## 1. 想定業種・サロンの種類（仮定）

- 業種: **エステ（プライベートサロン）**
- 設定: 都市部の個人経営フェイシャルエステ。完全予約制・1人サロン（仮定・架空）
- ターゲット: 20代後半〜40代女性、Instagram利用層、「自分へのご褒美」志向

## 2. 動画の目的

- **新規集客・体験予約の促進**（体験メニューへの導線を想定したリール広告の型）
- 営業デモとしては「この品質・この雰囲気の動画が作れます」を見せることが主目的

## 3. 尺・形式

| 項目 | 指定 |
|---|---|
| 尺 | 15秒（±3秒） |
| 画角 | 縦型 9:16（1080×1920） |
| 想定面 | Instagramリール／META広告（リール面） |
| 構成 | **1クリップ完結型**：AI生成クリップ1本（5〜10秒）＋冒頭フック・テキストオーバーレイ・CTAは編集で付加（生成回数を増やさない） |
| 使用モデル | 低コスト帯モデルを指定（Kling系 約6cr/生成、標準720p 約10cr/生成（推定・第三者情報））。高位モデル（Veo等）はこの回は使わない＝原価下限の実測が目的 |

## 4. 訴求ポイント

優先順に：
1. **施術の雰囲気・リラックス感**（世界観で見せる。効果は語らない）
2. 完全予約制・プライベート空間という事実ベースの特徴
3. 体験メニューの存在（価格はサンプルでは「体験メニューあり」の表現に留める。具体価格はダミーでも入れない＝営業先で誤解を生むため）

テキスト案（編集で載せる）：
- フック（0〜2秒）:「がんばった一週間、肌にもごほうびを」
- 中盤:「完全予約制のプライベートサロンで、ゆっくり自分と向き合う時間」
- CTA:「体験メニューはプロフィールから」

## 5. 使用素材

- **実写素材: なし（フルAI生成）**
- したがって以下が必須（表現ガイドv1.1）：
  - 「映像はAIにより生成されたイメージです」を視認可能なサイズ・秒数で表示（6.3）
  - 実在店舗と誤認させない（「当店の内観」等の文言は使わない）（6.2）
  - AI人物を「お客様」「スタッフ」として提示しない（6.2）→ 無人の空間カットまたは施術シーンの抽象的な描写を推奨

## 6. NGワード・NG構図（表現ガイドv1.1準拠）

**ワード（キャプション・テロップ・ナレーションすべて）：**
- 効果断定・保証系: 必ず／絶対／100%／誰でも／即効／1回で実感
- 医行為・効能系: 痩せる／脂肪燃焼・分解／セルライト除去／リンパの流れを改善／デトックス／毒素・老廃物／アンチエイジング／若返り／シミが消える／〜が治る／細胞活性化／医療級
- 最上級・No.1系: 日本一／最高／地域No.1／最安値
- 有利誤認系: 今だけ／本日限定／残り◯枠（事実でない限定）、取消線の二重価格
- その他: マッサージ（→「トリートメント」）／永久脱毛

**構図：**
- ビフォーアフター構図（左右比較・矢印・スライダー・「施術前/施術後」ラベル）は全面禁止（6.1）

**素材権利（6.4）：**
- BGMは商用広告利用可ライセンスのみ（アプリ内音源・SNS提供音源は使わない）
- フォントは商用利用可を確認済みのもののみ

## 7. 参考にするトーン・雰囲気

- **上質だが敷居は高くない**「親しみのある高級感」。ラグジュアリーホテル系の冷たい高級感には寄せない
- ビジュアル: 柔らかい自然光・暖色系・アロマ/タオル/観葉植物などの静物、スローでゆったりしたカメラワーク
- テキスト: 口語・ですます調・押し売り感なし（第7章OK例文のトーン）
- 音: 環境音系・アコースティック系の落ち着いたBGM（商用可ライセンス）

## 8. 生成プロンプトの方向性（案・調整可）

> 縦型9:16。柔らかな午後の自然光が差し込む小さなプライベートエステサロンの室内。ベージュとホワイトの内装、施術ベッドに清潔なタオル、湯気の立つアロマオイル、観葉植物。ゆっくりとしたドリーイン。人物なし（または手元のみ）。穏やかで温かい雰囲気、シネマティック、フォトリアル。

- 人物を入れる場合は「顔のアップを避けた施術の手元」までに留める（顔崩れQCコストと6.2リスクの両方を回避）
