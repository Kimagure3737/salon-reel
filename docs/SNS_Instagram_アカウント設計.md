## アカウント運用の基本設計

| 項目 | 設計 |
|------|------|
| 投稿比率 | A型（変身）＋B型（過程）＝7割／C型（完成動画のみ）＝3割 |
| 投稿頻度 | 週6本（Week2以降。テンプレ詳細は docs/SNS_投稿テンプレ3型.md） |
| 展開順 | Week1: Instagram Reelsのみ → Week2以降: TikTok／YouTube Shorts／Xへ同素材を横展開（SPEC §11） |
| DM運用 | インバウンドのみ（アウトバウンド営業DMは行わない＝SPEC §9） |
| 数値管理 | docs/SNS_数値管理シート.md に週次記録 |
| BGM | **Instagramアプリ内ライブラリからアップロード時に選曲**（急上昇トレンド×美容ジャンル使用率×サビ15〜30秒で選定）。Suno等のAI生成楽曲は使用しない（2026-07-05方針・詳細は投稿テンプレのBGMルール） |

## BGMリサーチ運用ルール（毎週月曜・2026-07-05追加）

- **毎週月曜：その週の投稿BGMをリサーチして決定する**
- リサーチ先（この順で確認）：
  1. Instagram Reelsの「急上昇」トレンドサウンド
  2. TikTok急上昇（Instagramより3〜7日先行してトレンドが来る）
  3. [Spotifyバイラルチャート日本版](https://charts.spotify.com/charts/view/viral-jp-weekly)
- 選曲基準：①美容・ネイル系の動画で使用されている ②直近1週間以内にバズった ③15〜30秒のサビが動画テンポに合う
- Suno等AI生成楽曲はBGMとして使用しない
- 選んだ曲名・アーティスト・使用予定投稿日を docs/SNS_数値管理シート.md の**BGM列**に記録する

## 撤退ライン（参照用・SNS戦略リサーチより）

| 時点 | 基準 | アクション |
|------|------|-----------|
| 30日 | 平均再生500未満＋保存率1%未満 | フォーマット全面改訂 |
| 90日 | 問い合わせ3件未満 | SNS主軸を見直し・DM併用へ回帰 |
| 180日 | 成約1件未満 | SNSを補助チャネルへ格下げ |

## コンプラ前提（全投稿共通・表現ガイドv1.1）

- 全投稿に「AIにより生成されたイメージです」または同等表示（6.3）
- 「制作費0円」「30分で完成」等の絶対表現は使用禁止。「従来の撮影コストと比べ大幅削減（当社実績比）」等の根拠ある相対表現のみ
- 施術結果と誤認させるBefore/After構図は禁止（6.1）
- 投稿前に表現ガイド第8章チェックリストを通す
