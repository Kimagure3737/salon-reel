## 1. モデル使い分け（実測ベース）

| 用途 | 第一選択 | 理由 |
|------|---------|------|
| 静物マクロ（ネイルチップ・ツール類） | **Kling 3.0** | 一発合格率が高い（#2①③・#3B）。低コスト |
| 空間・インテリア | **Seedance 2.0** | Klingは空間カットで煙が出やすい（#2②）。Seedanceは自然体 |
| 【確定NG仕様】 | — | **Kling 3.0は「No steam」指定でも煙が出る場合がある**（#2②実測）。空間系でKlingを使わない |

## 2. 標準設定【確定】と実測コスト

| モデル | 標準設定 | 実測コスト/生成 |
|--------|---------|---------------|
| Kling 3.0 | **sound off・std・5秒・9:16** | **7.5cr**（#3実測） |
| Seedance 2.0 | **std・720p・5秒・generate_audio: false・9:16** | **22.5cr**（#3実測） |

- BGMは編集で載せるため音声生成は常にoff
- 高設定の実測: Kling 66cr／Seedance 72cr（音声on・pro・長尺のいずれか（推定））＝**設定ミスで約9倍のコスト差**が出る
- 生成前に必ず `get_cost: true` でプリフライト（MCP経由の場合）

## 3. プロンプトの型（実績テンプレ）

```
[被写体・素材の具体描写], vertical 9:16.
[色調・小物]（業種の世界観に合わせる）
[光] Soft warm/bright natural light 系
[カメラ] Slow smooth dolly-in / gentle slow camera glide（速い動きは不自然になりやすい）
[スタイル] Photorealistic, shallow depth of field
No people. No text.（末尾固定）
```

**ネガティブプロンプト定型（入力欄がある場合）：**

```
people, face, hands, extra fingers, steam, vapor, mist, text, letters, logo,
watermark, harsh lighting, cluttered background, distorted objects
```

## 4. 構図の定石

- **無人・静物・空間カットは一発合格率が高い**（7生成中ボツ1回・煙起因のみ。再生成率2.3倍＜前提3〜5倍）
- 指・顔を映さない（AI破綻の最頻部位。ネイルは「チップの静物」、施術イメージは「ツールのマクロ」で表現）
- 要素数を絞る（歪みが出たら小物の記述を1つずつ削る）
- 色指定は複数クリップ間で共通にする（編集で並べた時の統一感）

## 5. コンプラ由来の構図ルール（表現ガイドv1.1参照）

- B/A構図の全面禁止（6.1）／AI人物を客・スタッフとして見せない（6.2）
- **アイラッシュ：AI目元アップ禁止**（AIまつげ＝実在しない施術結果の提示）
- ネイル：AIデザインは「デザインイメージ」明記（実例と誤認させない）
- フォトリアル生成物には編集時に「AIにより生成されたイメージです」表示（6.3）

## 6. MCP運用フロー【標準】

1. `models_explore` でモデル・パラメータ確認（初出モデルのみ）
2. `generate_video` に `get_cost: true` でコスト事前確認
3. 生成投入 → `job_status`（sync）で完了待ち（実測60〜180秒）
4. `transactions` で実消費crを確認 → 実効原価ログに記録（自己申告に頼らない）
